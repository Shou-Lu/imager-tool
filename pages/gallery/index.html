性能与限制

关于

本插件接入梦星的小图床公开 API，提供随机图、图库浏览、图片详情、统计与头像能力。

  • 聊天指令：/随机图、/图库列表、/图库信息、/图库统计 等。
  • 支持 V1 / V2 图库、标签筛选、WebP / PNG / 原图输出。
  • Token 仅用于服务端请求，不会拼接到公开链接中。
  • 配置与 AstrBot 插件配置面板共用同一份数据。

本插件为社区作品，与图床站点无隶属关系；请遵守站点使用规则与速率限制。
